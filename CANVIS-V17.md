# CadaGota v17 — Fitxes de plantes editables

- A Control privat es pot editar el nom, espècie, data de plantació i observacions de cada jardinera.
- Els llindars mínim/màxim i el temps màxim continuen al mateix formulari.
- Els selectors privats mostren el nom personalitzat després de desar.
- Executar `supabase/plantes-editables-v17.sql` **abans** de publicar la web.
- No canvia els panells públics ni envia configuració a l'Arduino.
- Els llindars d'humitat són de prova fins que es calibra la lectura RAW.
