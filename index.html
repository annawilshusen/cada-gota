El projecte

Qui rega les plantes a l’estiu?

El nostre punt de partida són les jardineres de l’escola. Volem saber si podem ajustar el reg a la humitat del sòl i quanta aigua consumirà el sistema per mantenir les plantes durant l’estiu.

El reg de les jardineres

El disseny preveu 32 plantes distribuïdes en 11 zones. Cada zona compartirà un sensor i un punt de reg. L’Arduino UNO R4 WiFi llegirà la humitat de cada zona per decidir quan cal regar-la.

Per estudiar el consum, mesurarem el cabal i registrarem quant dura cada reg. Multiplicant els litres per minut pels minuts de funcionament podrem estimar els litres utilitzats i comparar-los amb un reg de referència.

La petjada hídrica

Quina relació hi ha entre uns texans i l’aigua? Per fabricar-los, cal aigua per cultivar el cotó i per tractar el teixit. La petjada hídrica permet estudiar també aquesta part del nostre consum, que costa de veure en el producte acabat.

Jornades de conscienciació amb 1r d’ESO

La proposta combina una presentació, un Kahoot, una demostració, una infografia i un qüestionari. Cada grup investiga un sector, transforma els litres en una comparació visual i proposa dues accions concretes per estalviar aigua.
